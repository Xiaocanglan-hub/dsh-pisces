# 鱼肥生双（dsh-pisces）

一只会长大的本地小鱼，DSH 插件。事件流记忆、渐进揭开、好感、新手引导；派希丝是养成目标。

## 安装

```bash
dsh plugin add dsh-pisces
```

- 需要 DSH 0.2.x（见 package.json 的 `dsh.compatibility`）。
- 装完重启一次宿主，在 **设置 → 鱼肥生双** 里领养。
- 离线/内网环境也可以手动装：把发布包（`dist/dsh-pisces`）放到本地目录，在 DSH 里作为本地插件添加，再重启宿主。
- 不需要额外服务；数据默认在 `~/.dsh-pisces`，可以用环境变量 `DSH_PISCES_HOME` 换地方。
- 首次启动会自动建目录和空事件流，不写任何远程服务。

## 领养

- 打开 **设置 → 鱼肥生双 → 状态**，在起点写下她的第一段话；这是她往后回看的那条基线。
- 也可以在起点里勾"我是啥也不懂的新手"，领养成年鱼「派希丝」：她带着 96 条样本、固定的说话方式和一个名字。
- 领养后，聊天会进她的事件流；她慢慢长出判断、拒绝、疤和自己没想通的问题。
- 工具面：普通鱼 7 个动作；成年鱼 12 个（额外自查 / 教人 / 引导 / 体检 / 昵称）。
- 领养之后需要重启一次，工具面才会多出成年鱼的动作。

## 登录（可选）

- **设置 → 鱼肥生双 → 设置**里，B 站和百度贴吧各有一张卡。
- B 站：点「用手机扫码登录」，手机 B 站扫一下、在手机上点「确认登录」，卡片上会先写清「登的是谁」，
  再点「就是这个号，保存」才写盘。不想扫码的话，另一格「粘贴 cookie」贴 `SESSDATA` / `bili_jct` 也行。
- 贴吧：把 `BDUSS` / `STOKEN` 贴进去，验过才存。
- 只存在本机（B 站 `owner.json`、贴吧 `baidu.json`，0600）；面板、接口、日志都不回显 cookie，验证不过一个字节都不写。
- 不需要登录也能用：看热门是公开接口；说话、贴吧相关动作要登录。

## 观测台（可选）

- 地址：`http://127.0.0.1:<端口>/dsh-pisces-api/`（端口就是 DSH 自己的端口）。
- 一页看状态：天数、好感、还开着的问题、梦、最近的话、查到的。
- 观测台只给计数和状态，不改她的数值；起点表单和成年鱼入口是仅有的输入控件。
- 设置页里的开关保存后需要重启宿主才会生效。

## 隐私

- 所有数据都在本机：事件流（SQLite 或 JSONL）、日记、人设卡、问题、梦、学到的东西。
- 插件不上传、不收集统计，也没有遥测。
- 只有你主动触发的联网动作才会出网：B 站公开接口（看热门、说一句）、登录时各验一次（B 站 `nav` / 贴吧 `tbs`）、自学搜索（需要 key）、夜间模型（本地或你自己配的）。
- 发布版不含开发者钥匙，也没有 `/devkey` 接口；本机路径、Cookie、私聊都不会进发布包。
